# MERN Blog: frontend

React 19 + TypeScript + Vite single-page app for the MERN Blog.

See the [main README](../README.md) for setup, environment variables and feature documentation.

```bash
cp .env.example .env
npm install
npm run dev      # http://localhost:5173 (expects the API on http://localhost:5000)
npm run build    # production build in dist/
npm run lint
```
